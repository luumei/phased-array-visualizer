# Phased Array Visualizer

Interactive 3D visualization tool for understanding phased antenna arrays and beamforming.

---

## Overview

This project is a didactic visualization tool for exploring phased antenna arrays.

It enables intuitive understanding of how steering direction and array configuration affect radiation patterns in space. The focus is on conceptual clarity rather than full electromagnetic simulation.

---

## Live Demo

https://luumei.github.io/phased-array-visualizer

---

## Features

* Interactive 3D radiation pattern visualization
* Beam steering (theta and phi)
* Adjustable array size and element spacing (λ-based)
* Detailed and simplified calculation modes
* Clear representation of phase steering effects

---

## Usage

Adjust array parameters and steering direction to observe how the radiation pattern changes in real time.

---

## Concepts

* Phased arrays
* Beamforming
* Radiation patterns
* Element spacing (λ/2, center-to-center)
* Phase steering
